Web design

Website & Landing Page Design

Custom site and landing page design aligned to the client's branding, built with fully functional buttons and integrated back-end systems.

TAT~1 weekBuilt inGoHighLevelClientBusy Being Me Preparatory
The brief

Busy Being Me Preparatory had no website at all. Parents had no online way to learn about the daycare, schedule a tour, or enrol their child — every inquiry was handled manually.

Process
  1. Mapped the parent journey around three actions — learn about the daycare, book a tour, then enrol — and structured the site around them.
  2. Designed and built the full site in GoHighLevel, aligned to BBMP’s branding with fully functional buttons.
  3. Wired enrolment and tour scheduling end to end, so both run fully automatically with no manual follow-up.
  4. Added a live chat widget so parents can send inquiries straight from the site.
  5. Launched the finished site, fully operational.
Outcome

BBMP went from no web presence to a fully automated site where parents can enrol, book tours, and get their questions answered live — delivered in a week.
